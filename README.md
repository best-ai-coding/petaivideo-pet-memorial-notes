# Field notes: gentle AI pet memorial tributes from one photo

Working notes for turning a single dog or cat photo into a short vertical AI tribute clip — imagined scenes for remembrance days, not a real recording of a reunion.

## What this is for

When someone wants a respectful short video for a pet memorial post (Rainbow Bridge / Día de Muertos ofrenda style), a one-photo → 10-second 9:16 MP4 workflow is faster than stitching slides by hand. The clip should be labeled as an **AI tribute, not a real recording**.

## Practical checklist

1. Pick one clear JPG/PNG/WebP of the pet (face and body visible helps).
2. Choose a gentle memorial or trend scene template.
3. Review the free watermarked preview before spending credits.
4. Download the finished vertical MP4 (silent version / cover when available).
5. Caption honestly: AI-generated tribute.
